지식을 습득함에 있어서 어려운 부분은, 단순하게 지식의 습득 그 자체에서 오는 것이 아니다.
나에게 있어서 지식 습득에 있어서 가장 위험하고 어려운 부분은 어떠한 주제에 대해서, 그것을 모르지만 안다고 착각하는 것, Illusion of knowledge 이다. 이것은 교육학, 인지심리학, 전문가 양성 분야에서 공통적으로 이야기하는 주제이다.

### Bloom's Taxonomy
교육학에서 이를 구분하기 위해서 Bloom's Taxonomy 를 통해 단계를 나눈다고 한다. Bloom's Taxonomy는 학습자의 이해 수준을 기억 → 이해 → 적용 → 분석 → 평가 → 창조의 6단계로 구분하는 교육학적 모델이다. 단순히 "얼마나 많이 아는가"가 아니라, 지식을 가지고 어떤 수준의 사고를 할 수 있는가를 평가하는 것이 목적이다.

| 단계             | 의미                                  |
| -------------- | ----------------------------------- |
| **Remember**   | 사실, 용어, 정의를 기억하고 재현할 수 있다.          |
| **Understand** | 자신의 말로 설명하고 의미와 원리를 이해한다.           |
| **Apply**      | 새로운 문제나 상황에 지식을 적용할 수 있다.           |
| **Analyze**    | 구성 요소를 분해하고 관계와 원인을 분석할 수 있다.       |
| **Evaluate**   | 근거를 바탕으로 대안을 비교하고 판단할 수 있다.         |
| **Create**     | 기존 지식을 조합하여 새로운 아이디어, 설계, 해결책을 만든다. |


### Illusion of Explanatory Depth(IOED)
이 개념은 2002년 인지심리학자 Leonid Rozenblit와 Frank Keil의 연구에서 체계적으로 제시되었다. 우리 뇌는 '익숙함(Familiarity)'을 '이해(Understanding)'로 착각한다.

예를 들어 자동차 브레이크 변기, 자전거, 냉장고, 엘리베이터 모두 매일 사용한다. 그래서 우리는 "원리를 안다." 라고 착각하게 하지만, "브레이크가 작동하는 과정을 단계별로 설명해보세요." 대부분 중간에서 멈추게 된다. 연구에서는 참가자들에게 예를 들어 "변기는 어떻게 물이 내려갈까요?" 라고 질문하면  대부분 "잘 압니다." 라고 답하고 자신의 이해도를 7~9점 정도로 평가한다. 그 다음 연구자가 "좋습니다. 처음부터 끝까지 단계별로 설명해 보세요." 라고 하면, 갑자기 물탱크...압력이... 사이펀이...음... 그리고 다시 이해도를 물으면 7~9점이던 것이 4~5점으로 떨어지게 된다.

여기서 중요한 것은 중요한 것은 새로운 지식을 배운 것이 아니라, 자신의 착각을 깨달았다는 점이다.왜 설명하면 착각이 깨질까? 머릿속에는 대충 알고 있는 개념이 있다. 하지만 이를 설명하기 위해서는 A → B → C → D → E 논리적인 연결이 필요하다. 설명하다 보면 A는 아는데 B를 모르네? 를 발견하게 되고,  알고 있다는 착각, IOED가 깨진다.

이것의 원인은, 1/ Recognition(익숙함), 2/ Passive Learning, 3/ 전문가의 설명을 자신의 이해로 착각(전문가의 설명을 듣고 이해를 하지만, 자신이 설명할 수는 없음) 으로 보고있다.


### Feynman Technique - 리처드 파인만의 학습법
리처드 파인만이 이야기한 이 학습법은 어떤 개념을 자료 없이 자신의 언어로 설명하고, 설명이 끊기는 지점을 찾아 다시 학습하는 방법이다.

단순히는 다음과 같이 단계를 나누어 설명할 수 있다. 여기서 핵심은 어려운 단어를 쉬운 단어로 표현하는 것이 아니라, 자료 없이 설명을 생성하면서, 내 지식 구조의 빈틈을 발견하는 것 그 자체이다.
```
1. 학습할 개념을 선택한다. (개념의 범위를 좁힌다)
2. 초보자에게 가르치듯 설명한다. (정의 → 목적 → 작동 과정 → 결과 → 한계)

3. 설명하지 못한 부분을 찾아 다시 공부한다.
- 구체적인 빈틈을 분류하고 학습한다.
- 정의 빈틈: 용어를 정확히 정의하지 못함
- 인과 빈틈: A에서 B로 넘어가는 이유를 모름
- 과정 빈틈: 순서를 설명하지 못함
- 경계 빈틈: 언제 성립하지 않는지 모름
- 비교 빈틈: 비슷한 개념과 구분 못 함
- 적용 빈틈: 실제 사례에 연결 못 함
- 증거 빈틈: 주장을 뒷받침하지 못함

4. 설명을 단순화하고 예시·비유를 보완한다.
- 불필요한 용어 제거
- 생략된 인과관계 추가
- 순서 재배치
- 조건과 예외 명시
- 적절한 예시 추가
```



### Illusion of Knowledge를 피하기 위한 Check List

Bloom's Taxonomy, Illusion of Explanatory Depth(IOED) 를 적용하여 이를 분류할 체크리스트를 만들었다.

```
Level X. Metacognition (메타인지) - 이 단계는 Bloom보다 먼저 검사.

체크리스트
□ 내가 모르는 부분을 말할 수 있는가?
□ 자신 없는 부분이 어디인지 아는가?
□ 설명하다 막힌 부분이 있는가?
□ 자신감과 실제 능력이 일치하는가?
□ "왜?"를 세 번 물었을 때 답할 수 있는가?

Level 1. Remember (기억) - 용어와 사실을 기억하는 단계

체크리스트
□ 이름을 알고 있는가?
□ 정의를 말할 수 있는가?
□ 관련 용어를 구분할 수 있는가?
□ 핵심 키워드 3개를 말할 수 있는가?

Level 2. Understand (이해) - 의미를 이해하는 단계

체크리스트
□ 왜 존재하는지 설명 가능한가?
□ 어떤 문제를 해결하는가?
□ 한 문장으로 설명 가능한가?
□ 비전공자에게 설명 가능한가?
□ 예제를 하나 만들 수 있는가?


Level 3. Apply (적용) - 실제 사용할 수 있는 단계

체크리스트
□ 직접 구현 가능한가?
□ 새로운 상황에 적용 가능한가?
□ 실무 문제에 적용 가능한가?
□ 책과 다른 예제를 만들 수 있는가?

Level 4. Analyze (분석) - 다른 개념과 비교하고 구조를 분석하는 단계

체크리스트
□ 언제 사용하는가?
□ 언제 사용하지 않는가?
□ 다른 패턴과 비교 가능한가?
□ 장단점을 설명 가능한가?
□ 내부 구조를 설명 가능한가?

Level 5. Evaluate (평가) - 적절성을 판단하는 단계

체크리스트
□ 이것이 최선의 선택인지 판단 가능한가?
□ 다른 대안과 비교 가능한가?
□ 왜 이 선택을 했는가 설명 가능한가?
□ 트레이드오프를 설명 가능한가?
□ 반례를 만들 수 있는가?

Level 6. Create (창조) - 새로운 것을 만드는 단계

체크리스트
□ 새로운 예제를 만들 수 있는가?
□ 기존 개념을 조합할 수 있는가?
□ 개선안을 만들 수 있는가?
□ 새로운 설계를 만들 수 있는가?
□ 다른 사람에게 가르칠 수 있는가?
```

이것을 기반으로 agent를 만드는 것도 재미있을 것이다. 학습을 도와주는데 굉장히 유용한 도구가 아닐까 생각한다.
